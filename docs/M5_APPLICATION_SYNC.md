# M5 招聘进度同步

## 1. 已支持

### A. 招聘邮件导入（真实）

- 单个/多个 `.eml`（单批 ≤20）
- 逐条解析：发件人/主题/时间、企业/岗位、状态
- 逐条结果：成功 / 重复（幂等）/ 失败
- 用户确认后写入 `ApplicationEvent`
- 低置信度 → `needs_review`
- 重复邮件不重复生成事件
- 不执行 HTML/脚本

### B. 手动更新进度（真实）

- 选择已有申请
- 选择新状态、事件时间、来源、备注
- 新增 `ApplicationEvent`，不覆盖历史

### C. 官网跳转（真实）

- 打开官方招聘页
- 用户自行记录进度 / 导入邮件佐证
- **打开官网不会自动把状态改为 applied**

## 2. 明确不支持（不伪造）

- 邮箱 OAuth 自动同步（未实现 Provider）
- 招聘平台账号密码/Cookie 托管
- 官网自动登录/抓取申请状态
- 浏览器插件自动同步

页面不展示“邮箱已连接”或“官网已同步”。

## 3. 状态冲突

当前实现：

- 邮件导入时保留原始事件时间
- 用户确认时选择目标状态与时间
- 新事件追加，不覆盖历史
- 低置信度进入 `needs_review`

尚未实现：自动检测“导入事件时间早于当前状态”的冲突弹窗；当前依赖用户在确认界面人工判断。

## 4. 同步结果

`ApplicationImport` 记录：状态、置信度、重复、匹配申请、确认时间。
`ApplicationEvent` 记录：from/to status、event_time、source_type、evidence_type、verification_status。
