# CareerPilot 使用手册

面向**使用者**的操作说明：从注册到拿到 offer 的每一条路径，都在这里说清楚。
部署、迁移、备份脚本见 [`README.md`](../README.md)；二次开发见 [`AGENTS.md`](../AGENTS.md)。

> 适用版本：M1–M6 个人版（含 2026-10 三轮体验修复后的界面）。
> 下文默认服务已启动：Web <http://localhost:3000>，API 健康检查 <http://localhost:8000/readyz>。

---

## 1. 它能做什么，不做什么

**能做**

- 按关键词/企业/城市在**官方招聘站点**检索岗位，并把「搜索命中」和「已核验详情页」分开标注；
- 解析 PDF/DOCX 简历，生成**可编辑、可确认**的个人画像；
- 用画像对岗位做**可解释匹配**（技能 / 方向 / 偏好 / 经历 + 资格独立判断）；
- 记录投递进度、笔试面试预约，用日历看**明确的**日程；
- 用 Agent 工作台做多轮问答（找岗位、看匹配、查进度），异步执行、可取消、可刷新恢复；
- 可选：连接 QQ 邮箱 / Gmail，把招聘邮件里的进度建议变成**候选**，由你确认后才写入时间线；
- 本地备份与恢复。

**不做**

- 不自动投递、不自动填表、不代登录招聘平台、不抓取需要登录的页面；
- 不保存招聘平台密码或 Cookie；
- 不伪造岗位、不把「搜索摘要」当成完整 JD；
- 不把邮件发送时间当成面试时间。

## 2. 五分钟上手

1. 打开 <http://localhost:3000/login>，注册并登录（密码 ≥ 8 位）。
2. 左侧「简历管理」上传 PDF/DOCX（默认上限 10 MB）→ 在「我的画像」核对并点**确认画像**。
3. 左侧「岗位推荐」看推荐，或「发现岗位」自己搜；对感兴趣的岗位「收藏」或「登记申请进度」。
4. 在「投递看板」维护状态，在申请详情里**登记笔试/面试预约**，日程会出现在「面试日程」。

新账号的「概览」页顶部有同样的三步引导卡片。

## 3. 页面地图

| 页面 | 地址 | 用来做什么 |
|---|---|---|
| 概览 | `/dashboard` | 真实统计、最新招聘、最近进度、即将开始的日程 |
| 岗位库 | `/jobs` | 已核验（读到官方详情页）的岗位，可按条件筛选 |
| 发现岗位 | `/discover` | 官方站点直连检索，产出候选链接并核验 |
| 岗位推荐 | `/matches` | 基于已确认画像的推荐与资格判断 |
| 我的收藏 | `/saved-jobs` | 收藏列表，可取消收藏 |
| 面试日程 | `/calendar` | 只显示**已预约**的笔试/面试，月/周/列表三视图 |
| 导入岗位 | `/import` | 提交官方链接，或粘贴 JD 存为私有候选 |
| 简历管理 | `/resumes` | 上传、解析、设为画像来源 |
| 我的画像 | `/profile` | 编辑教育/经历/项目/偏好，确认画像 |
| Agent 工作台 | `/agent` | 多轮问答，实时进度，可取消 |
| 投递看板 | `/applications` | 申请记录（列表/表格/看板）、`.eml` 导入、邮件候选确认 |
| 设置 | `/settings/email` | 邮箱连接、测试、同步、解绑 |

手机上左侧栏会收起，点左上角**菜单按钮**打开导航。

## 4. 账号与登录

- 注册后自动登录；邮箱统一转小写存储。
- 连续登录失败会触发限流（返回 429），等待一段时间再试。
- 所有写操作都带 CSRF 校验；看到「CSRF 校验失败」时**刷新页面**再操作即可。
- 退出登录会清空本机保存的画像草稿，避免下一个账号看到上一个账号的输入。

## 5. 简历与画像

### 5.1 上传简历

1. 进入「简历管理」，选择 `.pdf` 或 `.docx`（默认 ≤ 10 MB，由 `MAX_RESUME_MB` 控制）。
2. 上传后系统会尝试提取教育、技能、经历。
3. 结果分两种：
   - **解析成功**：可以直接「应用到画像」。解析会按简历里的章节标题（实习经历 / 项目经历 /
     科研经历 / 获奖情况…）分栏：实习进「实习与项目经历」，项目与科研进「项目」，
     奖学金与竞赛不进这两栏；时间范围统一成 `2025.10 - 2026.01` 形式；
   - **文件已保存，但没能提取到文字（可能是扫描版）**：换文字版 PDF/DOCX，或直接在「我的画像」手工填写——不会影响后面所有流程。
4. 多条简历可设一条为「主简历」，应用解析结果时以它为准。

### 5.2 编辑与确认画像

「我的画像」可编辑五块内容：

| 区块 | 字段 |
|---|---|
| 基本信息与技能 | 一句话简介、技能标签 |
| 教育经历 | 学校、专业、学历、入学/毕业年份 |
| 实习与项目经历 | 企业、岗位、起止时间、做了什么 |
| 项目 | 项目名、**时间**、概述（简历里的项目与研究经历会自动填到这里；简历没写时间则留空，可手填） |
| 求职偏好 | 目标方向、城市、实习/校招、毕业年份 |

- 点**保存画像**只保存草稿，不参与匹配；点**确认画像**才会用于推荐和 Agent 匹配。
- 顶部显示「已确认于 …」表示当前版本已生效。
- **修改已确认的画像后会自动失效**，需要重新确认——这样不会用你没核对过的内容去算分数。
- 有未保存修改时，顶部会出现「有未保存的修改 · 立即保存 / 放弃修改」；直接离开页面时浏览器会提醒。
- 刷新或误关页面后，未保存的改动会**恢复回来**（草稿按账号隔离，不会串到别人账号）。
- 画像读取失败时页面会显示错误与**重新加载**，不会一直转圈。

## 6. 找岗位

### 6.1 发现岗位（`/discover`）

页面顶部有两个入口，作用不同：

**A. 企业官网直连检索**（当前已支持 7 家：腾讯、京东、字节跳动、小红书、哔哩哔哩、美团、MiniMax）

- 由服务端浏览器把关键词输入企业官方搜索框，读取真实岗位数据（标题、城市、招聘类型、完整 JD）；
- **不消耗搜索额度**，不依赖 `TAVILY_API_KEY`；
- 只覆盖校招 / 实习（美团会先切到「应届校招」，不含社招）；
- 默认开启「**跟随上方筛选**」：你在上方勾选的企业里，支持直连的会自动带入；手动点选会关闭跟随；
- 「**腾讯招聘项目**」下拉只在选中腾讯时出现（日常实习 / 应届实习 / 应届毕业生 / 青云计划），
  其他企业不适用该字段；
- 标题右侧显示「已支持 7 / 19 家」。**其余 12 家**（阿里巴巴、百度、得物、DeepSeek、360、小米、
  Kimi、携程、快手、网易、华为、拼多多）显示为灰色锁定按钮：
  点击会**直接打开该企业官网的校招搜索页**（新标签），并提示把找到的链接或 JD 粘到「导入岗位」；
  按钮悬停时会说明未适配的具体原因。
- 京东走官方 JSON 接口（速度快），但该接口**不返回城市**，所以京东岗位的城市显示为“城市未知”；
  MiniMax 由飞书招聘托管，走浏览器渲染，不带 `TAVILY_API_KEY` 也能用。

> 能不能直连取决于对方站点：是否要求登录、检索接口是否公开、列表是否由前端签名。逐家探测过，
> 未通过的会保持灰色而不是给一个点了必失败的按钮。

**B. 筛选与搜索**（企业 19 家、任何关键词）

1. 选择企业（可多选，默认勾选 10 家 P0：字节跳动、腾讯、阿里巴巴、百度、美团、小红书、哔哩哔哩、得物、DeepSeek、360）、
   关键词、城市、实习/校招、**岗位方向**（大模型 / LLM、Agent / 应用、算法、数据、后端、
   基础架构 / SRE、前端 / Web、客户端、测试 / QA、安全、产品、设计、运营 / 市场、其他）、
   发现窗口（7 天 / 30 天 / 不限）与排序；
2. 点**发现岗位**，走搜索索引（需要 `TAVILY_API_KEY`）；未配置 Key 时这条路径不可用，
   此时用上面的直连检索或「导入岗位」；
3. 结果分两类：
   - **候选**：只有链接或摘要，点「查看官网」自行确认；
   - **已核验**：成功读到官方详情页，进入「岗位库」。
4. 页面底部「询问 Agent」会把关键词、企业、城市、类型、方向写进提问（**不含**直连开关的选择），
   不会悄悄放宽范围；按钮下方会预览将要带上的条件。

### 6.2 导入岗位（`/import`）

页面顶部有两个模式：

| 模式 | 适用 | 结果 |
|---|---|---|
| **官方链接解析** | 任何企业的**岗位详情页**链接 | 百度走站点解析器（标记已核验）；其他企业用无头浏览器读取页面，给你一份待确认草稿 |
| **粘贴 JD** | 页面打不开、需要登录、或你已经有 JD 文本 | 保存为**仅本人可见**的私有候选（标记「用户导入」） |

官方链接解析的实际流程：

1. 粘贴岗位详情页 URL → 点**解析页面**；
2. 百度：直接解析成完整岗位，写入可检索岗位库；
3. 其他企业：系统用无头浏览器打开你给的页面，读取标题、企业与 JD 正文，显示为
   「浏览器读取 · 待你确认」的草稿；核对后点**保存为私有候选**；
4. 打不开或读不到正文（需要登录、页面动态加载）→ 自动切到粘贴模式并说明原因。

注意两点：

- **要粘详情页，不是列表页**。列表页上没有 JD 正文，人工复制也一样拿不到；
- 浏览器读取只访问公开页面，不登录、不绕验证码；读不到就回退到手填，不会编造内容。

粘贴时的字段：公司、岗位名称、城市、工作地点原文、岗位类型、JD 正文、任职要求、链接。
**链接域名不限**（私有候选不会去抓它，也不会自动核验）。

- 同一链接重复提交是幂等的，不会产生重复记录；
- 粘贴内容会原样保存（上限 2 万字符），不会清洗掉你的换行与标点。

### 6.3 候选详情（`/leads/{id}`）

- 显示来源链接、保存的 JD 正文、是否「仅本人可见」。
- **尝试核验**：读取官方页面；成功才升级为岗位库里的岗位。
- **登记到投递看板**：直接按这条候选创建申请记录并跳到申请详情；已登记过会直接打开原记录。

### 6.4 岗位库与岗位详情（`/jobs`、`/jobs/{id}`）

- 岗位库只收录**已读到官方详情页**的岗位。
- 详情页会显示单岗位匹配：总分、资格判断、符合的技能、简历暂未体现的技能、解释。
- 右上操作：**收藏岗位 / 取消收藏**、**加入待投递清单**、查看官网。
- 画像未确认时，匹配区域会提示先去确认，不会给出分数。

## 7. 推荐与匹配（`/matches`）

- 只使用**已确认**画像；未确认时页面显示「先确认画像，才能给出匹配」。
- 每条推荐包含：分数、资格判断（符合 / 不符合 / 未判断）、推荐原因、符合与暂未体现的技能。
- 「**只看符合我资格的岗位**」默认开启，被隐藏的数量会写在旁边；取消勾选可查看全部。
- 资格「不符合」的岗位仍可能出现，并列出不满足的硬性条件（例如毕业年份、学历）——它说的是「能不能投」，不是「该不该投」。
- 每条可**收藏 / 取消收藏**、**登记申请进度**、跳转岗位详情或官网。
- 操作失败（例如服务暂时不可用）会在页面顶部显示红色提示，不会静默失败。

## 8. 投递看板与预约

### 8.1 投递看板（`/applications`）

- 三种视图：**列表 / 表格 / 看板**，顶部可按岗位名、企业、状态筛选。
- **新建申请**两种方式：
  - 从岗位页点「登记申请进度」（自动带上企业、岗位与链接）；
  - 点「仅登记官方链接」，手填公司、岗位名称、官方链接、状态、备注。
- **待投递岗位**单独一块，来自岗位详情的「加入待投递清单」。
- 行内状态下拉可直接改状态，保存后立即生效。

### 8.2 `.eml` 与邮件候选

- 看板页可上传招聘通知 `.eml`：先**预览**解析结果，确认后才写入时间线。
- 连接邮箱后，同步只产生「**邮箱同步待确认**」候选；你点**确认更新**才改状态，点**忽略**丢弃。
- 邮件没有明确写出的状态不会被推断。

### 8.3 申请详情（`/applications/{id}`）

- 顶部显示当前状态与「最近确认」时间；下拉切换状态后，标题与时间线会**立即刷新**。
- **登记笔试 / 面试预约**：
  - 类型：面试 / 笔试 / 在线测评；发生时间按你的本地时间填，系统换算成 UTC 存储；
  - 两种模式：
    - **新增一轮预约**：保留已有预约，适合真实的多轮面试或多场笔试；
    - **改期（仅替换选中的预约）**：从下拉里挑出要替换的那一条同类型预约，其他轮次不受影响；
  - 改期只能替换**同类型**预约；已经改期或取消的记录不能再被替换（会提示刷新后重试）；
  - 保存后立即出现在「面试日程」。
- 「有效预约」区块列出当前仍生效的预约，每条可**取消**；取消后日历不再显示，时间线仍保留记录（标注已被改期/取消）。
- 「状态时间线」按时间列出状态变更、来源（手动/邮件）、证据摘要与备注，纠错不覆盖历史。
- 注意区分两个时间：**预约时间**（面试什么时候）与**记录时间**（你什么时候登记的，即「最近确认」）。

### 8.4 面试日程（`/calendar`）

- 只显示**预约**：笔试、面试、在线测评。投递、初筛等状态变更不进日历。
- 三种视图：月 / 周 / 列表；「即将开始」与「历史日程」分开，不会重复出现。
- 顶部「登记预约」跳到投递看板，打开某条申请即可录入；空态里也有同样引导。

## 9. Agent 工作台（`/agent`）

### 9.1 提问

- 左侧「新建对话」开新会话；输入框下方有示例：「帮我找北京的大模型实习」「哪些岗位更适合我的简历？」「看看我最近的申请进度」。
- 提交后**立即返回**，任务在后台执行，页面实时显示阶段与工具调用；断线会自动降级为轮询，不用手动刷新。
- 运行中可点**停止任务**；执行有硬上限（300 秒），超时会标记为失败/超时而不是一直转。
- 刷新页面会恢复最近一次的运行状态、等待确认或最终结果；切换到别的会话后，旧任务的结果不会写进新会话。

### 9.2 需要确认画像时

- 若本次需要完整匹配而画像未确认，页面会显示「这次任务需要先确认画像才能继续」，并提供：
  - **去确认画像**：跳到 `/profile`；
  - **已确认，继续**：确认后回到这里继续同一任务。
- 如果画像仍未确认，继续会被服务端拒绝并提示原因——不会给出未确认画像的分数。

### 9.3 看结果

结果卡片按类型分开：

- **岗位**：企业、岗位、城市、类型、核验状态、官网与详情链接；
- **匹配**：分数、资格、符合/未体现技能，资格不符的会标注「资格不符 · 仅供参考」；
- **另有 N 个候选未列入本轮条件**：被你的企业/城市/方向条件排除的候选，折叠在这里，不计入推荐；
- **申请进度**：状态与申请详情链接。

正文只会推荐「符合条件」的岗位；当没有符合条件的结果时，会明确说「没有符合条件的岗位」，而不是把最接近的岗位包装成推荐。

## 10. 邮箱同步（`/settings/email`，可选）

1. **QQ 邮箱**：在 QQ 邮箱设置里开启 IMAP 并生成**授权码**（不是登录密码），在页面填入邮箱 + 授权码。
2. **Gmail**：需要部署时配置 `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` / `GOOGLE_REDIRECT_URI`，未配置时页面会明确提示。
3. 连接后点**测试连接**；成功后系统每 15 分钟增量同步一次（`MAILBOX_SYNC_INTERVAL_MINUTES` 可调），也可点**立即同步**。
4. 可**暂停自动同步 / 开启自动同步**，或**解绑**（删除已保存的加密凭据）。
5. 同步结果只写「候选」，确认后才进时间线；「扫描 / 候选 / 重复」数量会列在连接卡片下方。

> 凭据用 Fernet 加密保存；`MAILBOX_SECRET_KEY` 丢失后旧凭据不可解，需要重新绑定。

## 11. 数据、隐私与边界

- 每个账号的数据完全隔离：岗位、收藏、申请、画像、Agent 会话都按账号隔离。
- 私有 JD（粘贴导入）**只有你自己可见**，不会进入公共岗位库。
- 邮箱凭据加密存储，日志不记录密码、授权码、简历正文与密钥。
- 系统不会替你投递、填表或登录招聘平台；「查看官网」只是打开链接。

## 12. 常见问题

**Q：为什么推荐页显示「先确认画像」，而岗位详情有分数？**
两者用同一套规则：只有确认过的画像才参与匹配。若这里提示未确认，去「我的画像」点确认即可，两处会同时恢复。

**Q：画像改了，为什么推荐分数没变？**
修改后画像会自动失效，需要重新点「确认画像」；未重新确认前，推荐与详情都不会用新内容算分。

**Q：上传简历后提示「文件已保存，但没能提取到文字」？**
通常是扫描版或图片型 PDF。换文字版 PDF/DOCX，或在「我的画像」手工填写，其他功能不受影响。

**Q：日历是空的，但我确实有面试？**
日历只认**预约**。打开投递看板 → 对应申请详情 → 「登记笔试 / 面试预约」，填时间保存即可；邮件里明确写了面试时间并确认后也会出现。

**Q：改期后旧时间还在？**
先看选的是哪种模式：**新增一轮预约**会保留原有预约（适合真实的多轮面试）；**改期**只替换你在下拉里选中的那一条，其他轮次仍有安排。想彻底移除某一场，直接在那条预约上点「取消」。

**Q：Agent 说「没有符合条件的岗位」，可我看到下面还有候选？**
下面折叠的是**被你的企业/城市/方向条件排除**的候选（「另有 N 个候选未列入本轮条件」）。想放宽限制，直接说「不限城市」或「扩大到其他公司」再问一次。

**Q：结果卡片里有「资格不符 · 仅供参考」，为什么还显示？**
卡片会保留这类岗位并标注原因，便于你判断是否值得冲；它们不计入推荐结论。

**Q：收藏错了怎么取消？**
收藏页每行都有「取消收藏」；岗位详情页的按钮会随状态变成「取消收藏」；推荐卡片上也能取消。

**Q：手机上找不到导航？**
左上角菜单按钮打开抽屉；点任意链接会自动收起。

**Q：页面提示「CSRF 校验失败」或一直 401？**
刷新页面重新登录。CSRF Token 与登录态绑定，长时间不操作会过期。

**Q：Agent 一直显示运行中？**
可点「停止任务」。任务有硬上限（300 秒），超时会被标记；如果反复出现，检查后端 Worker 与 Redis 是否正常（见 README 的故障排查）。

## 13. 备份与恢复

```bash
./scripts/backup.sh                                    # 数据库 + 上传文件 + 邮箱密钥 + 校验清单
./scripts/restore.sh --from backups/<stamp> --dry-run  # 预演
./scripts/restore.sh --from backups/<stamp>            # 默认恢复到测试库
./scripts/restore.sh --from backups/<stamp> --force    # 覆盖真实库（需手动输入库名确认）
```

`mailbox_secret.key` 必须与数据库备份分开保管；恢复后贴回 `.env` 才能解开邮箱凭据。
详见 [`docs/M6_BACKUP_RECOVERY.md`](M6_BACKUP_RECOVERY.md)。

## 14. 已知限制

- Gmail 同步依赖自备 Google OAuth 凭据；未配置时只能用 QQ 邮箱与 `.eml` 导入。
- 在线搜索需要 `TAVILY_API_KEY`；未配置时只能用 5 家企业（腾讯/字节/小红书/B站/美团）的官方直连检索与手动导入。
- 其余 12 家企业暂未接入官方直连：站点需要登录、检索接口未公开或列表结构不稳定；
  未接入的企业点击按钮会打开官网搜索页，可手动挑岗位后用「导入岗位」保存。
- 链接解析分两条：百度走站点解析器（写入公开岗位库）；其他企业用无头浏览器读取详情页，读到的内容按私有候选保存。需要登录、验证码或纯图片的页面读不到，会回退到粘贴 JD。
- Agent 依赖 LLM 配置（`LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL`），三者缺一时页面会明确提示不可用。
- 移动端已适配导航与主要列表，但真机触屏与 iOS 键盘场景未做自动化回归。
