# CareerPilot 功能状态

更新：2026-11-17。面向开源使用者；M2–M6 文档记录当时的设计与评估，操作以 [使用手册](USER_GUIDE.md) 和当前代码为准。

| 模块 | 已有能力 | 使用前提 / 限制 |
|---|---|---|
| 账号与隔离 | Cookie Session、CSRF、登录限流、用户资源隔离 | 公网部署先阅读 [安全说明](../SECURITY.md)，关闭无邮箱验证的密码重置 |
| 岗位发现 | 官网直连、官方域名检索、候选核验 | 7 家支持自动发现；其他企业可手动导入，第三方站点变化可能影响解析 |
| 岗位导入 | 官方详情链接预览、粘贴 JD | 粘贴内容为个人私有，不能替代官方核验 |
| 岗位维护 | 手动复核、发现新增、明确下线后软归档 | 默认不自动定时更新；清理、归档查看与恢复需要管理员 |
| 简历与画像 | PDF / DOCX 提取、编辑、保存与确认 | 扫描件可能无法提取文字，匹配前必须本人确认 |
| 推荐与匹配 | heuristic_v1 可解释评分、独立资格判断 | 分数不是录取概率，需自行核对官网要求 |
| Agent | 多轮上下文、异步队列、SSE、等待确认、取消与恢复 | 需要配置模型；实时搜索另需搜索服务，外部调用可能收费 |
| 投递与日历 | 申请看板、时间线、明确预约、改期 | 不代替本人在招聘官网投递，不把状态变化当作预约 |
| 邮件 | QQ IMAP / Gmail、增量同步、候选确认 | 需自行配置邮箱；本轮文档验收未连接或测试真实邮箱 |
| 公开网站 | 介绍、截图切换、免登录手册与部署说明 | 静态站，与完整业务服务分开；首次启用 Pages 后可访问 |
| 运维 | Docker、迁移、备份恢复、响应式界面 | 不提供托管服务；使用者负责数据与加密密钥保管 |

## 本轮文档验证

- 使用独立演示数据库截取 10 张功能截图；图中人物、岗位、企业与预约均为虚构。
- Agent 图片为预置演示对话，未调用模型，不代表真实检索质量。
- Web 手册提供全文内容检索定位、分组目录、阅读位置提示、手机目录与原图入口；公开站复用同一份内容。
- 本轮验证：后端 439、前端 79 项测试通过；公开站桌面、平板、手机 3 项浏览器用例通过。
- 不自动投递、不自动填表、不托管招聘平台密码或 Cookie、不绕过登录或验证码。

## 数据流

岗位、画像、申请与凭据密文由自己的部署保存。使用外部模型、搜索、邮箱或企业官网时会访问相应服务；相关问题、画像、JD、检索词等可能发送给配置的服务商。请根据实际提供商条款决定是否启用。

## 公开文件边界

[发布说明](OPEN_SOURCE_RELEASE.md) 说明发布包取舍。开发期运行日志、旧截图、网页快照及完整本地 Git 历史不包含在默认导出中。源码许可证为 MIT；依赖许可证及企业网站内容仍遵循各自条款。
